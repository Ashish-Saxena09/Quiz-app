# Simple Quiz

This is a simple quiz project made using HTML, CSS and JavaScript.

Users can answer multiple-choice questions and see their final score at the end.

## Features

* Multiple-choice questions
* Select an answer
* Score calculation
* Next question button
* Play again option

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.

## Project Files

* `index.html` - Structure of the quiz
* `style.css` - Styling of the quiz
* `script.js` - Questions and quiz logic
